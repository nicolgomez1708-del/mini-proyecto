# Reflexión sobre el Aprendizaje Adquirido

## Introducción

Durante el desarrollo de este proyecto de bases de datos relacionales, tuve la oportunidad de aplicar los conocimientos adquiridos como aprendiz del SENA en un entorno práctico. La construcción de una base de datos para la gestión de una biblioteca me permitió comprender de manera más profunda la importancia del diseño, la organización y la administración eficiente de la información.

## Lo Aprendido

Uno de los principales aprendizajes fue el diseño de bases de datos relacionales, identificando entidades, atributos y relaciones entre las diferentes tablas. Comprendí la importancia de las claves primarias y foráneas para garantizar la integridad de los datos y mantener relaciones consistentes entre las tablas.

También fortalecí mis conocimientos en el lenguaje SQL mediante la creación de tablas, inserción de registros y desarrollo de consultas para obtener información específica. Aprendí a utilizar restricciones, índices y validaciones que contribuyen a mejorar la seguridad y el rendimiento de la base de datos.

Adicionalmente, adquirí experiencia en el uso de herramientas tecnológicas como Docker, PostgreSQL, pgAdmin y Visual Studio Code. Estas herramientas facilitaron la creación de un entorno de trabajo organizado y permitieron comprender procesos utilizados en entornos profesionales de desarrollo.

## Dificultades Encontradas

Durante la ejecución del proyecto surgieron algunos inconvenientes relacionados con la configuración de los contenedores y la carga inicial de los datos. Fue necesario revisar mensajes de error, analizar registros de ejecución y corregir inconsistencias en las relaciones entre las tablas.

Aunque estas dificultades representaron un reto, también fueron una oportunidad para desarrollar habilidades de análisis y resolución de problemas, entendiendo la importancia de revisar cuidadosamente la estructura y los datos antes de ejecutar los procesos.

## Conclusión

Como aprendiz del SENA, considero que esta experiencia fue muy valiosa para fortalecer mis conocimientos y desarrollar nuevas habilidades técnicas. El proyecto me permitió comprender mejor el funcionamiento de las bases de datos relacionales y la importancia de utilizar herramientas adecuadas para su implementación y administración. Los conocimientos adquiridos servirán como base para afrontar proyectos más complejos y continuar mi crecimiento profesional en el área del desarrollo de software.
